# Contributing

Keep changes small and tied to observed behavior. Read AGENTS.md before work. Handy with Apple Screen Sharing is the supported integration; other remote clients need independent evidence.

Run `make test-fixtures`, `make privacy-scan` and `make build-menubar-app`. Include the operating system, Handy version, signing mode and actual test path in a pull request. Build success does not prove remote insertion, startup approval or permission continuity. Hardware tests need a local Mac, microphone input, granted permissions and a disposable remote text field.

Do not include private history, screenshots, settings, signing keys or full logs. Preserve MIT notices and provenance. The project has no required hosted services or third-party Swift packages.
